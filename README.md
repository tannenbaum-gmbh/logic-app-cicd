# logic-app-cicd

Sample for Logic Apps CI/CD.

## Dev Container

This repository includes a devcontainer at `.devcontainer/devcontainer.json` for Azure Logic Apps Standard development and deployment workflows.

It preinstalls:

- Azure CLI
- Azure Functions Core Tools v4
- PowerShell and GitHub CLI
- VS Code extensions for Logic Apps, Azure Functions, Azure auth/resource management, YAML, and CI/CD workflows (GitHub Actions + Azure Pipelines)
